## Exercise 1
- 题目指出乘法器的延迟是60ns,加法器的延迟是45ns,建立时间是10ns,保持时间是5ns,CLK-to-Q时间是10ns,要求我们计算出最大
的时钟频率。
- 注意题目中说了输入也是clocked register,所以对于这个CL循环电路来说，$T >= t_{cq} + t_{mul} + t_{add} + t_{setup}$,
即 $T >= 125ns$, 同时验证一下holdtime, $t_{hold} <= t_{cq} + t_{CL}$,显然满足，所以最大时钟频率为 $f_{max} = \frac{1}{T} = 8MHz$.

## Exercise 2
- 在上面那个电路中，加法器和乘法器严重影响了时钟周期，考虑设计一个流水，使用一个中间8位的寄存器来存储乘法器的结果，
第一部分$T_1 = t_{cq} + t_{mul} + t_{setup} = 80ns$, 第二部分$T_2 = t_{cq} + t_{add} + t_{setup} = 65ns$,所以最大阶段是80ns,最大时钟频率为12.5MHz.
- 对比得知我们的时钟周期大大提升，意味着可以更快的输入数据，只有一个小问题是由于我们使用了一个中间寄存器，所以我们的流水版本的输出会比非流水版本慢一个周期。
